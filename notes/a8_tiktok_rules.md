# A8.net × TikTokアフィリエイト ルールまとめ

出典: A8.net「TikTokを使ったアフィリエイトガイド」 https://www.a8.net/as/TikTok/
(ユーザーが貼り付けた内容をもとに整理。ガイド内の情報は2023/10/31時点のもので、変更されている可能性あり)

## 1. 広告リンクの作り方
1. スマホ版: ログイン後TOPの「広告リンク作成」をタップ
   PC版: 「プログラム管理」>「参加中プログラム」
2. 提携中プログラムの一覧から「広告リンク作成」をタップ
   - SNSへの掲載に条件があるプログラムもあるので、掲載前にプログラム詳細を確認する
3. 「掲載サイト」欄で広告を載せるTikTokアカウントを選び、「広告リンクを表示」をタップ
4. 使いたい素材を選び、【SNS・note用】をタップ
5. 掲載するSNSで「TikTok」を選び、リンクをコピーする
   - リンクは掲載するSNSごとに作る

### 商品リンクを使う場合
- 【商品リンク】→【フリー素材生成】を選ぶ
- 「リンク先URL」に誘導したい広告主サイトのページURLを入れ、掲載サイトでSNSを選んで【商品リンク作成】をタップ
- 「商品リンク」と書かれたプログラムでしか使えない。使えるプログラムでもフリー素材がない場合がある

## 2. TikTokへの掲載方法
- リンクを載せられるのは**プロフィール欄だけ**。URLは**1つだけ**
- プロフィールにリンクを載せる条件: **フォロワー1,000人超** または **ビジネスアカウントへの切り替え**
- 設定手順: プロフィール → プロフィール編集 → ウェブサイトを追加 → リンクを入れて保存

### 方法A: 広告リンクを直接載せる
- 広告主のサイトへ直接誘導する
- 投稿の商材ジャンル・アカウントのジャンル・リンク先の商材ジャンルをそろえる
- 必ず【PR】などを入れて、広告だと分かるようにする

### 方法B: ブログや別サイトのURLを載せる
- 誘導先のブログや別サイトに広告リンクを載せる
- 複数のSNSやブログを持っているなら、リンクまとめページのツールを使う方法もある
- TikTokとブログのジャンルをそろえる。広告リンクにはPR表記を入れる

## 3. PR表記・情報開示(必須)
- 2023/10/1施行の景品表示法の指定告示(ステマ規制)により、PR等の表記が必要
- TikTokでは、ブランド・製品・サービスを宣伝する投稿は「コンテンツの情報開示設定」をONにするよう定められている
  - プロフィールのリンクでアフィリエイトしていて、それに関係する投稿をする場合もONにする
  - 手順: 投稿時の設定 → 「コンテンツの情報開示」をON → 「ブランドコンテンツ」にチェックして保存 → 投稿に「プロモーション」と表示される

## 4. 収益を上げるコツ(A8.net公式)
1. **ジャンルを1つに絞り、発信内容をそろえる**
   リンクは1つしか載せられないので、投稿とリンクの内容がずれると成果につながらない
2. **ユーザーが求めるコンテンツを出す**
   広告色が強いと流される。共感を呼ぶ動画、トレンドの音楽やハッシュタグ、旬の話題、視聴者参加型の企画やチャレンジ動画など
3. **ブログや他のSNSに誘導する**
   短い動画では詳しく説明できないので、詳しい情報はブログで伝える。いったん別の場所を挟むと広告色も薄まる

## 5. 注意事項・禁止事項
- 使うTikTokアカウントは、必ずA8.netに「サイト登録」する
- **本人が管理・運営している**アカウントに限る
- **一般公開のアカウント**に限る(非公開・鍵付きアカウントは不可)
- 著作権・肖像権を守り、迷惑行為をしない
- A8.netから投稿やページの開示を求められたら、すぐに応じる
- アカウントが凍結・削除されても、A8.netは責任を負わない
- 違反が見つかった場合、提携解除・成果キャンセル・強制退会の可能性がある

### TikTokで宣伝が禁止されている業種(ブランドコンテンツポリシー)
- 成人向けの性的な商品・サービス
- 酒類(ノンアルコール飲料も含む)
- タバコ製品(電子タバコ・ベイプも含む)
- 避妊用の商品・サービス
- マッチングアプリ・サービス
- 金融商品・サービス(原則禁止)
- ギャンブル
- 医薬品・ヘルスケア商品
- 減量商品・サービス

詳細: https://www.tiktok.com/legal/page/global/bc-policy/ja

### ハッシュタグの注意
- 薬機法に触れる言葉を使わない
- 虚偽・誇大と受け取られる言葉を使わない
- ハッシュタグを組み合わせると、上の表現に当たってしまう場合があるので注意する

## 6. 自分の計画(転職ジャンル)に当てはめたメモ
- 転職(人材紹介)は禁止業種に入っていない → ジャンルとして使える
- 3本目の動画に出てきた「脱毛」「ホワイトニング」は医療・ヘルスケアに当たる可能性、「ダイエット食品」は減量商品に当たる → TikTokでは避ける
- ビジネスアカウントで始めれば、フォロワー0人からプロフィールにリンクを貼れる
- 転職系の投稿でも毎回「ブランドコンテンツ」をONにし、PR表記を入れる
- 「年収が必ず上がる」「絶対ホワイト」のような言い切りは、ハッシュタグも含めて使わない
- 方法B(noteを経由する)は、noteアカウントと組み合わせられる
