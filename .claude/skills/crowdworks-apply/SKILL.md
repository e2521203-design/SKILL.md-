# クラウドワークス案件の整理と応募文の作成

## 1. 案件の内容を取得する
- URLが送られてきたら WebFetch で開く
  - 開けなければ、環境の許可ドメインに `crowdworks.jp` が入っていない可能性がある。その場合は利用者に案件本文のコピーを頼む
- ログインが必要なページは開けない。利用者のログイン情報は求めない

## 1.5 案件を探す場合(「いい仕事を探して」と言われたとき)
- 一覧ページ `https://crowdworks.jp/public/jobs` はJavaScriptで描画されるため読めない
- **カテゴリページ**なら取得できる。HTML内の `data="{...job_offers...}"` にJSONで一覧が埋め込まれている
  - 例: 文字起こし=55、秘書業務=150
  - `num_application_conditions` が応募人数、`project_contract_hope_number` が募集人数
- 依頼主の本人確認・評価は一覧にないため、候補の詳細ページを開いて確認する
- 規約でスクレイピングが禁止されているため、**人が見て回る程度の量**に抑える(一覧2〜3ページ、詳細5件程度まで)。定期的な自動巡回はしない

## 2. 案件を整理する(表にする)
- 報酬(固定/時間単価)と、手数料20%を引いた手取り
- 作業量の見積もり
  - AIで下書きし、人が確認する前提の作業時間
  - 見積もった時給
- 納期、応募状況(応募人数と募集人数)
- 依頼主の信頼度: 本人確認、評価数、発注ルールチェック
- 表示されている報酬と本文の金額の食い違い
- AIを使ってよいか(本文に禁止の記載がないか)

## 3. 評価する(応募する/見送る)
次の基準に照らして結論を出す(詳しくは `notes/goals.md`)。
- **良い案件**
  - 見積もり時給が1,500円以上
  - または、単価は低いが簡単でAIで数をこなせる
  - 継続案件の見込みがある
- **危ない兆候**
  - 高額すぎる報酬
  - LINEなど外部への誘導
  - 初期費用や教材費がかかる
  - 仮払いなしで作業を始めさせる
  - 本人確認なし・評価0件(これ自体は即見送りにしないが、注意として伝える)
- クラウドワークスの規約で禁止されている自動化(スクレイピングや自動応募)は提案しない

## 4. 応募文を作る
- 構成:
  1. あいさつ
  2. 依頼内容の理解(本文の要件を具体的に拾う)
  3. 作業方法
     - AIツールを使う場合は正直に書く
     - 人が確認して仕上げることを書く
     - ツールの利用に問題があれば指示に従う、と添える
  4. 納期と作業できる時間
  5. 依頼主への質問を2〜3個(依頼をよく読んだことが伝わるもの)
  6. 締め
- 名前は利用者の登録名「M,C」を使う(`[お名前]` にしない)
- 実績は作らない。利用者のプロフィールにない経験は書かない。分からない部分は `[ ]` にして、利用者に埋めてもらう
- 400〜700字程度。丁寧だが簡潔にする
- 応募ボタンを押すのは利用者本人

## 5. 定期リサーチ(ルーティンから実行されたとき)
- 手順1.5〜4を実行し、結果を `notes/job_reports/YYYY-MM-DD.md` に保存する
  - 候補は上位3〜5件
  - 各候補について、整理表・評価・「AIでどこまで自動化できるか」・応募文(名前は「M,C」)を書く
  - 詐欺の疑いがある案件は、理由を添えて「見送り」欄に1行ずつ書く
- 過去のレポートに載せた案件IDは繰り返さない(`notes/job_reports/` を確認する)
- 応募はしない。利用者がレポートを読み、気に入った案件だけ自分で応募する
- 保存したら `claude/` で始まるブランチにコミットしてpushする

## 6. 選ばれた案件の自動化手順を作る
利用者が「この案件に決めた」「この案件を受注した」と言ったときに行う。
- `notes/jobs/<案件ID>.md` を作り、次の内容を書く
  1. 作業内容の分解: 何を受け取り、何を納品するか
  2. 各工程を「AIに任せる/人が確認する/人がやる」に分類する
  3. 使うツールと準備: 例えば文字起こしなら音声認識(Whisper等)、ケバ取り・整文はClaude
  4. 具体的な手順: そのまま実行できる番号付きのステップ
  5. 品質チェックリスト: 納品前に人が確認する項目
  6. 1件あたりの作業時間と時給の見積もり
- 依頼主がAIの使用を禁止していないか必ず確認する。禁止なら自動化しない
- 依頼主から受け取ったデータの扱い(外部AIに渡してよいか)を確認事項として書く

## 7. 記録する
- 検討した案件の結論は `notes/goals.md` の「経過」に1行で追記する
